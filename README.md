# Елена Горячева — школа маникюра

Стек: Next.js (App Router) + TypeScript + Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Структура

- `src/app` — маршруты (App Router)
- `src/components` — переиспользуемые UI-компоненты
- `src/content` — единая точка правды по контенту: курсы, контакты, навигация
- `src/types` — типы данных (курсы, отзывы, кейсы)

## Статус

Этапы 1–9 из ТЗ выполнены: аудит, дизайн-токены, каркас проекта, layout/header/footer,
типизированная модель курсов с 7 программами из раздела 11 ТЗ, главная страница
(раздел 9 ТЗ), каталоги курсов `/offline` и `/online` с карточками отдельных программ
`/offline/[slug]` и `/online/[slug]`, страница «Об эксперте» (`/about`, раздел 10 ТЗ),
страница «Результаты» (`/results`, раздел 13 ТЗ), страница «Отзывы» (`/reviews`, раздел 14
ТЗ) — обе с честными placeholder-слотами вместо кейсов, работ и отзывов, которых пока нет —
и страница «Вопросы» (`/faq`, раздел 15 ТЗ) с категориями вопросов поверх `homeFaq`.

Также добавлено мобильное меню (`src/components/MobileMenu.tsx`) — на ширинах уже собранного
хедера ниже `lg` навигация была полностью недоступна (только логотип), это блокировало доступ
со смартфона ко всем перечисленным страницам.

Все разделы из `primaryNav` (`src/content/site.ts`) реализованы. Осталось: юридические страницы
из `footerLegalLinks` (`/legal/privacy`, `/legal/terms`, `/legal/refund`) и подтверждение
реальных контактов, адреса и цен со статусом `placeholder` (раздел 18 ТЗ) — без этого раздела
кнопки записи на страницах курсов не станут активными.

Данные со статусом `placeholder` в `src/content/*.ts` требуют подтверждения перед публикацией —
см. раздел 18 исходного ТЗ.
