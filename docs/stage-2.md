# Этап 2: онлайн-сценарий и подбор курса

Продолжение этапа 1 отдельным коммитом в PR №5. Публикация в master не входит в этот пакет.

## Что изменено

- Главная: прямое предложение онлайн-курсов, две программы, один подбор, методика, работы и отзывы, обучение онлайн, преподаватель, тематический FAQ, один офлайн-блок и финальный выбор.
- Убраны отдельные повторные блоки боли, выбора формата и раскрывающихся аудиторий. Очные программы остаются в меню и отдельном блоке.
- Онлайн-каталог: карточки и сравнение сразу после первого экрана. Убраны дубли философии, боли, результатов и поддержки. Метаданные не обещают открытые цены всех курсов.
- Финальные CTA ведут к сравнению программ либо обсуждению в Telegram, а не одинаково рекомендуют всем курс материалов.
- FAQ на главной и в онлайн-каталоге посвящён онлайн-выбору, тарифам и оформлению.
- В описании поддержки больше не смешиваются продление поддержки и продление доступа к записям.
- Подбор учитывает опыт, задачу и формат. Абсолютному новичку не предлагаются продвинутые программы. Онлайн-запрос не заменяется очным курсом.
- Если подходящего подтверждённого маршрута нет, показано объяснение и ссылка в Telegram. Самоучке без подтверждённой базы не предлагается автоматическая покупка «Логики форм».
- Для пользователя с базой, принимающего оба формата, онлайн — основной вариант по материалам/формам; офлайн может быть альтернативой.
- В опросе есть возврат к предыдущему шагу, изменение ответов и повторный запуск. Выбранные ответы сохраняются и обозначены. Фокус переводится к новому шагу без автоматической прокрутки.
- В FACTS.md записано решение Галины: пока остаётся Telegram, цены и сроки доступа не придумывать.

## Проверка и ограничения

- 77 автоматических тестов: все 72 комбинации ответов и 5 ключевых сценариев. Проверяются существование курсов, соответствие формату и ограничения по подготовке.
- Проверки npm test, npm run typecheck, npm run lint; production build — в GitHub Actions (локальная среда ранее выдавала uv_resident_set_memory).
- Тесты алгоритма не заменяют визуальную и интерактивную проверку браузера. Desktop/mobile и внешний переход в Telegram требуют отдельной приёмки.
- Юридические страницы, неизвестные сроки доступа, цена и тарифы «Логики форм» остаются открытыми. Этот пакет их не решает.
- Следующие задачи: проверка адаптивности, меню и сравнения на телефоне, увеличение отзывов, детализация программ после ответов Елены.
