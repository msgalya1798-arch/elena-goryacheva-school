# Этап 1: навигация и прозрачное оформление

## Изменения

- Кнопка шапки «Подобрать обучение» ведёт к интерактивному опросу; FAQ содержит прямую ссылку на него.
- Для якорей задан отступ под липкую шапку.
- На странице Елены используется имеющийся реальный портрет.
- С главной убран незаполненный блок выпускников; из очных программ и онлайн-каталога убраны полосатые заглушки. Случайные работы не приписаны конкретным курсам.
- Карточки «Логики материалов» ведут к «Программе и тарифам», первый экран курса — к выбору тарифа.
- Кнопки тарифов прямо указывают Telegram. Рядом объяснено, что нужно сообщить курс и тариф; цена не изменена. Автоматическая оплата и выдача доступа не обещаны.
- У «Логики форм» уровень и аудитория приведены к уже существующему ответу FAQ: необходима база.
- Добавлены неинтерактивный lint, typecheck и проверка production-сборки в GitHub Actions.

## Проверка

- Локально: typecheck, lint, git diff --check.
- Production build локально блокируется средой: ENOENT / uv_resident_set_memory. Для полноценного результата использовать Verify site в pull request.
- Визуальная проверка desktop/mobile и внешнего перехода Telegram пока не выполнена для этой версии. Наличие кода адаптивности не считается проверкой на телефоне.

## Открытые задачи — не считать решёнными этим этапом

- Юридические страницы /legal/terms, /legal/privacy, /legal/refund по-прежнему отсутствуют. Нужны утверждённые документы; сайт пока не готов к полной приёмке продажи.
- Утвердить цену и тарифы «Логики форм», срок доступа к записям «Логики материалов», правила оплаты, возврата и поддержки.
- Подтвердить, сохраняется ли ручное оформление в Telegram или нужен прямой платёж.
- Проверить документами точное название и статус выдаваемых сертификатов.
- Следующий пакет: убрать дубли главной, поднять курсы в каталоге, доработать подбор. Текущий алгоритм не использует опыт при выборе: требуется отдельное исправление и проверка всех сценариев, особенно абсолютного новичка с выбором онлайн.
- Доработать mobile-меню, сравнение курсов, увеличение отзывов; провести проверку в браузерах.
- Изменения предназначены для отдельной ветки и ревью. Этот этап не включает слияние в master или публикацию основного сайта.
